# 端末差・文字拡大へのレイアウト対応（2026-09-19）

## 方針

基準画面はFigma `aT1PdPy4Lu6bC8oX78H4xb` の `580:7035`（測定中）、`580:7045`（姿勢登録）、`580:8053`（ホーム）。390px幅・標準文字では既存の位置と余白を維持する。

- 短い見出し、ボタン、キャラクター名、時間・割合・スロット番号は単位の途中で改行しない。必要なものに一行表示と枠内縮小を適用する。
- 説明文は文字サイズを一律無効にせず自然に折り返し、後続要素とカードの高さが追従する。
- 測定・登録カードは通常フローで配置し、文字が増えてもキャラクターに重ならず、カードの下までスクロールできる。
- ホームはQRボタン・説明の実測高さに合わせてヒーローを伸ばす。コレクションの件数はひとまとまりで次行に移れる。
- 取得済みカードは固定高さを解除。大きな文字ではタグを縦に並べる。未取得カードは番号と2列グリッドを維持する。
- 結果の時間・割合はfontScale > 1.2または6文字以上の時間で縦積み。数字と%は同じTextに含める。モーダルの内側はViewにし、親ScrollViewがカード全体をスクロールする。
